PalLaw Rules Studio

Visual map editor and JSON validator for regional Palworld server combat rules.

Visual Region Authoring

Draw polygon zones on the interactive Palworld map to mark safe zones, PvP combat areas, and custom stage locations.

Schema Validation & Offline Export

All rules are validated in real-time against the PalLaw configuration schema. Export clean, copy-ready PalLaw.json directly to your game server directory.

Local and Private

Rules Studio runs 100% inside your browser. No server uploads or telemetry.
