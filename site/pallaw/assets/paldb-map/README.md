# Bundled world map tiles

These 16 WebP tiles contain Palworld world-map imagery at zoom level 2
(`z2x0y0.webp` through `z2x3y3.webp`).

Palworld map imagery and related game assets are the property of Pocketpair,
Inc. Their inclusion in this unofficial fan-made editor does not claim
