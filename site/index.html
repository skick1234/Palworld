Frequently asked questions

Questions and answers

What is PalLaw?

PalLaw is a free, standalone, offline C++ UE4SS mod for dedicated Palworld servers. It allows server operators to draw custom regional polygons on the game map and define distinct combat rules per region.

What is PalOrbit?

PalOrbit is a cloud-hosted SaaS platform and companion UE4SS mod providing Cloud Zone Studio, live player tracking on interactive maps, Discord account linking, role-based privileges, and web starter kit claims.

How does regional combat work?

On PvP-enabled servers, PalLaw and PalOrbit enforce combat rules authoritatively on the server. If a damage event takes place where either the attacker or defender is inside a protected zone, the damage is cleanly canceled.

Is this website collecting analytics or personal data?

No. The website operates with a strict Content Security Policy forbidding network tracking requests. PalLaw Rules Studio runs 100% client-side in your browser.
